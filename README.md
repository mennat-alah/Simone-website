# Simone Website Clone

A front-end practice project recreating the Simone personal portfolio website from Route Academy using HTML, CSS, and Bootstrap 5.3.

## About the Project

This project was built to practice front-end development by recreating an existing website design from scratch. The goal was to improve my understanding of HTML structure, CSS styling, Bootstrap components, and responsive layouts.

Rather than simply copying spacing values, I tried to estimate and recreate the margins, padding, and distances between elements by observing the original Simone website from Route Academy. This helped me practice paying attention to visual details and translating a design into code.

## What I Learned

While building this project, I practiced:

- Structuring a multi-section webpage using HTML.
- Using Bootstrap 5.3 grid, components, and utility classes.
- Combining Bootstrap utilities with custom CSS.
- Creating CSS animations using `@keyframes`.
- Implementing hover effects and transitions.
- Working with spacing, alignment, and typography.
- Adjusting layouts for different screen sizes.
- Improving my ability to recreate an existing website design by visual observation.

## Challenges

One of the main challenges was estimating the spacing and dimensions of elements from the original website. I tried to work out the margins, padding, and proportions visually instead of relying on predefined measurements.

This helped me understand that recreating a design requires more than writing code; it also involves observation, experimentation, and continuous adjustment.
